# RuangBola V2

Prototipe platform non-profit/gotong royong untuk ekosistem pembinaan sepak bola Indonesia.

Fitur demo:
- Homepage responsif
- Dashboard
- Form kontribusi dengan localStorage
- Kebutuhan dan filter
- Direktori organisasi
- Peta ekosistem mockup
- Pustaka belajar
- Prinsip tata kelola/perlindungan anak
- Jalur pembinaan 6–9 sampai senior

Belum termasuk backend, autentikasi, pembayaran, GIS nyata, verifikasi produksi, atau consent management produksi.


## Perbaikan V2 Final
- Memperbaiki `RB.render()` agar view benar-benar dijalankan.
- Menambahkan fallback sederhana jika JavaScript dinonaktifkan.


## V3 Modern UI
- Visual system diperbarui dengan Manrope + DM Sans, glass navigation, gradient hero, cards, shadows, dan responsive mobile menu.
- Tidak mengubah konsep non-profit, safeguarding, atau struktur data demo.
